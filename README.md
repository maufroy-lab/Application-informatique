# 04 — Application Informatique

Ce dépôt contient le code source, la documentation et l'ensemble des livrables
du projet **Application Informatique**, réalisé dans le cadre du dossier de
Validation des Études Supérieures (VES).

## Structure du dépôt

| Dossier | Contenu |
|---|---|
| `docs/` | Documentation complète du projet (présentation, analyse, architecture, conception, tests, bilan) |
| `src/` | Code source de l'application (architecture en couches : core, application, infrastructure, ui) |
| `tests/` | Tests automatisés (unitaires, intégration, fonctionnels) et jeux de données de test |
| `config/` | Fichiers de configuration par environnement |
| `data/` | Données d'exemple et schémas de données |
| `scripts/` | Scripts de build, d'installation, de gestion de base de données et de déploiement |
| `assets/` | Ressources graphiques (icônes, images, captures d'écran) |
| `benchmarks/` | Résultats de mesures de performance et de mémoire |
| `deployment/` | Fichiers et documentation de déploiement (Docker, packages) |
| `.github/` | Workflows CI/CD et templates GitHub |
